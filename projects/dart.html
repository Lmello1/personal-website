DART — Distributed Autonomous RF Tracker


DART (Distributed Autonomous RF Tracker) is a multi-node radio direction finding system that uses Time Difference of Arrival (TDOA) to locate radio transmitters. Each node consists of a Raspberry Pi 3 Model A+, an RTL-SDR Blog V3, a u-blox NEO-M8N GPS receiver, and a Heltec LoRa 32 V3 (SX1262). The system is fully self-contained with no internet or infrastructure dependency — all inter-node communication runs over LoRa only.


Node Hardware


Each field node pairs a Raspberry Pi 3 Model A+ with an RTL-SDR Blog V3 for RF capture, a u-blox NEO-M8N GPS receiver for timing/positioning, and a Heltec LoRa 32 V3 (SX1262) for the wireless backhaul to the master station. This keeps every node small, battery-friendly, and independent of any local infrastructure.


GPS-Referenced Timestamping


TDOA positioning lives or dies on timing accuracy, so each node needs its IQ samples referenced to a common clock without modifying the SDR's crystal. DART solves this by attenuating the GPS receiver's 1PPS signal and injecting it into the RF path through a directional coupler, where it shows up as a detectable power spike in the IQ stream once per second. Nodes use that spike to measure their actual TCXO sample rate and correct for drift, giving every sample an accurate GPS-referenced timestamp. Each node continuously caches 30 seconds of IQ data in RAM, keyed by GPS second, sampled at 2.4 MS/s.


Master Station


The master station is a laptop running a Flask web application with a Leaflet map, a live waterfall display, and a Reticulum LoRa interface. When the operator identifies a signal of interest by drawing a box on the waterfall, the master sends a tune request to all nodes, followed by a collect request specifying a GPS second, sample offset, sample count, and an optional decimation bandwidth.


LoRa Backhaul


Nodes respond sequentially on a shared 915 MHz LoRa channel (SF7, BW500, roughly 2,500 bytes/sec effective throughput), transmitting zstd-compressed IQ windows back to the master. Keeping the entire link on LoRa means DART can be deployed anywhere without relying on cell service, Wi-Fi, or any other existing network.


TDOA Positioning


Once the IQ windows from each node arrive at the master, it cross-correlates them using GCC-PHAT to compute the time difference of arrival between node pairs. Those TDOA values are converted into a position fix, displayed on the Leaflet map as hyperbolic lines of possible transmitter location for each node pair along with a shaded probability area showing the most likely position of the transmitter.


Status


DART is an active, ongoing build — future posts will cover individual subsystems in more depth, including the antennas used on each node (like the flat-pack 3D printed discone built for wideband node reception).
